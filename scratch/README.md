# Scratch de desarrollo

Scripts one-off usados durante el desarrollo/investigación (checkeo de datos,
reprocesos manuales, limpieza local, pruebas aisladas, etc.).

**NO forman parte del aplicativo.** No se importan desde `src/`, no se despliegan
y no se garantiza que sean correctos o estén actualizados.

La suite de tests solo vive en `tests/` (ver `pytest.ini` → `testpaths = tests`),
por lo que estos scripts no interfieren con CI.
